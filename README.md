# Versión 0.0.1
Version inicial. Windows Forms Sistema POS para parqueadero inicialmente hecho .Net 4.8. 

El objetivo principal de este proyecto es ofrecer un sistema POS que ayude a las parqueaderos de Colombia al menos que posea 10 puestos. 

## Alcance y Funciones
- Debe permitir registrar ventas.
- Debe permitir imprimir en impresoras relacionados a un sistema POS.
- Debe poder ser ejecutado en un .exe o instalador sencillo de entender.
- Debe Permitir la configuración del sistema.
- Debe permitir manejo de roles
- Debe permitir registro de clientes.

## Alcance opcional por ahora
- permitir realizar pagos en linea.
- Permitir analisis de datos de ventas.
- Funcionar con el sistema NFC con tarjetas.
