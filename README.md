# Versión 0.0.3
Sistema POS para parqueadero inicialmente hecho .Net 4.8 y Windows Forms.  

El objetivo principal de este proyecto es ofrecer un sistema POS que ayude a las parqueaderos de Colombia al menos que posea 10 puestos.

## Alcance, funciones y tareas pendientes
- Debe permitir registrar otras ventas como por ejemplo registro de cascos y artículos.
- Debe Permitir visualizar un patio de parqueadero y registrar la entrada y salida de vehículos.
- Debe permitir imprimir en impresoras relacionados a un sistema POS.
- Debe poder ser ejecutado en un .exe o instalador sencillo de entender.
- Debe permitir la configuración del sistema POS. Modificar el logo, nombre del negocio, dirección, teléfono, correo electrónico y otros datos, horario y tarifas.
- Debe permitir manejo de roles
- Debe permitir registro de clientes o mensualidades.
- Debe permitir anular ventas.
- Debe permitir realizar reportes de ventas detallada, resumen y generar PDF.
- Debe permitir realizar copias de seguridad de la base de datos.
- Debe permitir restaurar copias de seguridad de la base de datos.
- Debe permitir conectarse a una base de datos SQL local.
- Debe permitir registrar ventas por medio de código de barras.
- Debe permitir visualizar la información de los clientes y sus ventas por medio de un grafico.
- Debe permitir registrar egresos y gastos del negocio.
- Crear un documento de ayuda para el usuario final. Manual de usuario.
- Crear un documento de ayuda para el desarrollador. Manual tecnico.
- Crear un documento de levantamiento de requerimientos y diseño del sistema. Documento de requerimientos y diseño.
